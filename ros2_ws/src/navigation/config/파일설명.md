# Multi-AMR Nav2 설정 파일 설명

## 1. 파일 목적

이 폴더의 설정 파일은 **AMR 1과 AMR 2가 각각 독립적으로 Nav2를 사용하도록 분리하기 위한 파일**입니다.

```text
AMR 1 → /amr1/*
AMR 2 → /amr2/*
```

현재 Isaac Sim에서 사용하는 주요 토픽은 다음과 같습니다.

```text
AMR 1
/amr1/cmd_vel
/amr1/odom
/amr1/scan

AMR 2
/amr2/cmd_vel
/amr2/odom
/amr2/scan
```

---

## 2. 파일 구성

```text
navigation/config/
├── nav2_amr1.yaml
├── nav2_amr1.yaml.backup
└── nav2_amr2.yaml
```

### nav2_amr1.yaml
AMR 1 전용 Nav2 설정 파일입니다.

주요 TF Frame:

```text
amr1/odom
amr1/base_link
amr1/base_footprint
```

### nav2_amr2.yaml
AMR 2 전용 Nav2 설정 파일입니다.

주요 TF Frame:

```text
amr2/odom
amr2/base_link
amr2/base_footprint
```

### nav2_amr1.yaml.backup
AMR 1 설정을 수정하기 전의 백업 파일입니다.

---

## 3. AF3.yaml과 차이

```text
AF3.yaml
→ 공장 지도 설정

nav2_amr1.yaml
→ AMR 1 Nav2 설정

nav2_amr2.yaml
→ AMR 2 Nav2 설정
```

즉,

> **AF3.yaml은 지도 파일이고, nav2_amr1/2.yaml은 각 AMR의 자율주행 설정 파일입니다.**

---

## 4. 전체 구조

```text
공용 Map (AF3)
      │
      ├── Nav2 AMR 1
      │      └── /amr1/*
      │
      └── Nav2 AMR 2
             └── /amr2/*
```

---

## 5. 다음 작업

다음에는 두 Nav2를 한 번에 실행하기 위한 Launch 파일을 만들 예정입니다.

```text
multi_amr_nav2.launch.py
```

최종 목표:

```text
/amr1/navigate_to_pose
/amr2/navigate_to_pose
```

각 AMR에 서로 다른 목표를 보내 독립적으로 자율주행시키는 것입니다.
